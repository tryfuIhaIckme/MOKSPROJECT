> **Symmetry-BioPredictor** — это передовая программная платформа для предсказания газопермеации (диффузии) в металлоорганических каркасах (MOF). В отличие от классических моделей, наша система использует **теорию групп** и **симметрийный резонанс** для достижения беспрецедентной точности в дизайне биосенсоров.

---

## 🧪 Научная концепция

Традиционные методы предсказания диффузии газов в пористых материалах опираются на изотропные параметры: **PLD** (диаметр лимитирующего окна) и **LCD** (наибольшая полость). Однако они игнорируют анизотропию и геометрическое соответствие формы молекулы форме поры.

### Наш прорыв: «Симметрийный резонанс»
Мы интегрировали в пайплайн машинного обучения точечные группы симметрии ($O_h$, $T_d$, $D_{\infty h}$, $C_{2v}$ и др.). 
Наша модель математически проверяет гипотезу **геометрического перекрытия**: 
Когда элементы симметрии молекулы-гостя (Guest) коррелируют с элементами симметрии порового окна (Host), возникает эффект "облегченной диффузии" — **Symmetry Match**.

**Ключевой дескриптор:**
$$SFF = \frac{PLD - \sigma_{gas}}{|G_{host}| - |G_{guest}| + \epsilon}$$
*Где $SFF$ — Shape Fit Factor, учитывающий стерические и симметрийные ограничения одновременно.*

## 🚀 Ключевые возможности

### 1. Интеллектуальный прогноз (AI Engine)
Использование градиентного бустинга **CatBoost**, оптимизированного через **Optuna**, для предсказания коэффициентов диффузии $log(D)$ и термодинамических параметров $Q_{st}$. Модель обучена на базе **CoRE MOF 2019** с учетом более 14,000 структур.

### 2. Интерпретируемость (Explainable AI)
Внедрение **SHAP (SHapley Additive exPlanations)** позволяет декомпозировать каждый прогноз. Профессор может видеть вклад каждого параметра (размера, пористости или симметрии) в итоговый результат. Больше никаких "черных ящиков".

### 3. Автоматическая экстракция симметрии
Интеграция с библиотекой **Pymatgen** позволяет программе "на лету" анализировать файлы кристаллической структуры `.cif` и определять точечные группы пор без участия человека.

### 4. Виртуальная 3D-лаборатория
Интерактивный рендеринг через **py3Dmol**. Визуальное сопоставление формы молекулы биомаркера и архитектуры порового канала в реальном времени.

## 🖥️ Интерактивный интерфейс (In-Silico Bio-Designer)

Приложение реализовано на базе **Streamlit** и представляет собой полноценную рабочую среду для исследователя. Интерфейс разделен на три логических модуля:

### 1. Панель конфигурации (Dynamic Dashboard)
В левой части экрана расположена панель управления параметрами MOF. Вы можете изменять геометрические характеристики каркаса в реальном времени:
*   **Слайдеры геометрии:** PLD, LCD, Пористость.
*   **Выбор симметрии:** Переключение точечных групп окна поры (от простых до сложных $m-3m$).


### 2. Научная аналитика (SHAP Insights)
Вкладка «Научный анализ» отображает **SHAP Waterfall Plot**. 
Это визуальное доказательство вклада симметрии:
*   **Красные блоки:** Факторы, ускоряющие диффузию (например, идеальное совпадение симметрий).
*   **Синие блоки:** Барьеры (стерические затруднения или несоответствие форм).


### 3. Визуализация в 3D (Virtual Lab)
Модуль на базе `py3Dmol` позволяет вращать кристаллическую решетку и сопоставлять её с геометрией газа. Это критически важно для оценки того, как молекула ориентируется при входе в поровое окно.

## 🛠️ Технический стек и установка

Проект объединяет лучшие инструменты из мира Data Science и вычислительной химии:

*   **Machine Learning:** [CatBoost](https://catboost.ai/) — градиентный бустинг, устойчивый к категориальным признакам симметрии.
*   **Chemistry Core:** [Pymatgen](https://pymatgen.org/) — для глубокого кристаллографического анализа.
*   **XAI:** [SHAP](https://github.com/slundberg/shap) — для интерпретации вкладов признаков.
*   **Frontend:** [Streamlit](https://streamlit.io/) + [Plotly](https://plotly.com/) + [py3Dmol](https://3dmol.csb.pitt.edu/).

### 📦 Быстрая установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your_username/Symmetry-BioPredictor.git
cd Symmetry-BioPredictor
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
streamlit run app.py
```
